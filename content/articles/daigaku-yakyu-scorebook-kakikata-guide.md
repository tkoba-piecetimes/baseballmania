大学野球部に入ったばかりの1年生や、マネージャー・学生スタッフになったばかりの部員の中には、「スコアブックを任されたけれど、記号が多くてどこから覚えればいいのかわからない」と感じている人もいるのではないでしょうか。スコアブックは、試合の経過と選手の成績を一枚の紙に残すための記録です。慣れるまでは難しく見えますが、NPB（日本野球機構）は公式サイトで「野球は『投げる、打つ、守る、走る』の4つの繰り返しですから、起こるプレイは限られていて、スコアブックをつけることはそれほど難しくはありません」と説明しています。

この記事では、NPBが公開している「NPB式スコアブックの記入方法」を一次情報として、試合前に書くこと、1打席ごとの記録、走者・交代の記録という順に基本を整理します。そのうえで、チームで使っている様式が違う場合の考え方や、リーグ戦の観戦を使った練習の進め方も紹介します。

## スコアブックは何のために書くのか

NPBの公式サイトのコラムによると、現在のNPB式スコアのもとになった「慶応式」は、1910年に慶應義塾大学野球部のスコアラーだった直木松太郎氏が考案した記録法です。直木氏は記録の目的として「試合状況を永久に伝えること」と「各組各選手の成績算出の基礎をつくること」の2点を挙げたと紹介されています。つまりスコアブックは、試合の振り返りに使えるだけでなく、打率や防御率といった成績の元データにもなります。

大学野球のチームでも、記録は次のような場面で使われます。

- 試合後の振り返りで、どのイニングに何が起きたかを確認する
- 打者ごとの打球方向や、投手の被安打の傾向を確認する
- シーズンを通して、個人成績やチームの攻撃パターンを集計する

記録が正確であるほど、あとから見直せる情報の質も上がります。逆に、記入の基準がぶれると集計の信頼性が下がるため、「何をどの記号で書くか」をそろえることが大切になります。

## 早稲田式と慶応式の違いと、自分のチームの様式の確認

スコアブックの記入方法には「慶応式」と「早稲田式」の2種類があります。NPBの説明では、NPBの公式記録員がつけているのが慶応式で、一般に普及しているのが早稲田式です。大きな違いは、早稲田式には補助線が入っていますが慶応式には入っていないこと、また塁の位置が異なることとされています。

このため、市販のスコアブックやチーム内の先輩の書き方が早稲田式の場合、NPB式の記号をそのまま当てはめると、紙面の配置が合わない場合があります。本記事で紹介する記号はNPB式（慶応式）の公式資料に基づくものです。実際に使い始める前に、次の2点を確認しておくと混乱を避けやすくなります。

- チームで使っているスコアブックの様式（早稲田式か、慶応式か、独自の書式か）
- 失策・安打の判断など、チーム内で記録の基準を決めている人（学生スコアラーの先輩や、連盟の記録担当者）

なお、国際大会などでは打撃記録と投手記録を別のシートに分ける形式も使われており、世界で統一された書式があるわけではないという解説もあります。「唯一の正解の書き方」があるわけではなく、「同じチーム・同じ大会の中で記号と基準がそろっていること」が実務上の目安になります。

## 試合前に書いておく項目と守備位置番号

NPBの資料では、試合が始まる前に次の項目を記入するとされています。

- 試合の年月日
- 対戦チーム
- 対戦回数
- 球場
- 審判員
- 両チームの先発メンバーおよび守備位置

守備位置は次の数字で記入します。まず、これは完全に暗記しておくと、以後の記録がとても楽になります。

| 数字 | 守備位置 |
| --- | --- |
| 1 | 投手 |
| 2 | 捕手 |
| 3 | 一塁手 |
| 4 | 二塁手 |
| 5 | 三塁手 |
| 6 | 遊撃手 |
| 7 | 左翼手 |
| 8 | 中堅手 |
| 9 | 右翼手 |
| DH | 指名打者 |

試合が始まったあとは、試合開始時刻・入場者数・試合終了時刻と試合時間も適宜記入します。大学野球のリーグ戦でも、公式記録として残すべき項目は連盟の記録用紙の指定に従うため、開幕前に記録用紙の様式を確認しておくと安心です。

## 1打席の記録の基本①：ボールカウントとアウトの記号

### ボールカウントは投球順に記入する

NPB式では、ボールカウントを6つの記号で表します。見逃しのストライク、空振りのストライク（ファウルチップを含む）、ボール、ファウルボール、バントを試みて空振りしたストライク、バントを試みたファウルボールの6種類です。これらを、所定の欄に投手の投球順に左から右へ記入していきます。盗塁や暴投、ボークなど、打者の打撃行為と関係のないプレイが投球の途中で起きた場合は、いつ起きたかを示す専用の印を付けます。

### 打者がアウトになったときの記号

打者がアウトになったときは、次の記号でその種類を示します。

| 記号 | 意味 |
| --- | --- |
| SO | 三振してすぐにアウトになった場合 |
| K | 第3ストライクを捕手が捕えなかったので、打者が走者となり一塁に進む状態となった三振（振り逃げ） |
| F | フェアフライ（飛球） |
| FF | ファウルフライ（邪飛球） |
| L | ライナー（直球） |
| BH | バント・ヒット（犠打にならないバントのゴロ） |

ゴロでアウトになったときは記号を使わず、送球が渡った順に守備位置の数字で書きます。たとえば二塁ゴロを二塁手が処理して一塁手に送球した場合は「4-3」です。また、犠打や犠飛の場合は、アウトの種類を囲んで示します。

スコアの記入は、四角いマス目に分数の要領で、分子にアウトの種類、分母にそのイニングのアウト数を書きます。たとえば「二死目のライトフライ」なら、分子が「F-9」、分母が「2」になります。野手が本来の守備位置ではない塁のベースカバーに入ったときは、一塁ならA、二塁ならB、三塁ならC、本塁ならHを、守備位置の数字の後ろに付けて示します。投手が一塁ベースカバーに入ったゴロであれば「1A」といった書き方です。

## 1打席の記録の基本②：出塁・安打・失策の記号

### 四死球や野手選択などの記号

打者が安打以外で出塁したときや、進塁・走塁に関するプレイには、次の記号を使います。

| 記号 | 意味 |
| --- | --- |
| BB | 四球 |
| B* | 故意四球 |
| D | 死球 |
| Fc | 野手選択 |
| O | 盗塁 |
| W | 暴投 |
| P | 捕逸 |
| bk | ボーク |
| KW | 振り逃げ暴投 |
| KP | 振り逃げ捕逸 |

NPBの資料では、1番打者から9番打者はアルファベットの小文字（a〜i）を使って表すとされています。得点や残塁、相手投手の自責点による得点にも、それぞれ専用の記号があります。

### 安打と失策の書き分け

安打で出塁したときは、打球が飛んだ方向と種類を記入します。NPB式では、単打・二塁打・三塁打・本塁打のほか、ゴロの安打・飛球の安打・ライナーの安打・内野安打など、打球の性質を示す記号が用意されています。失策で出塁した場合は、失策した野手の守備位置番号に失策の印を付けます。送球による失策では、送球が高すぎた、低すぎた、左にそれた、右にそれたという区別も記入します。

ここで悩みやすいのが、「ヒットか失策か」という判断です。この判断はスコアラー個人の感覚ではなく、公認野球規則の記録に関する規則（9.00）に基づいて行われます。NPBの記録解説ページでは、公認野球規則の9.00がダウンロード資料として公開されています。判断に迷う打球が出たときは、仮の記録をつけておき、試合後にチームの記録担当者と確認しながら規則を読み直す習慣をつけると、記録のぶれが減ります。

## 走者・選手交代の記録

走者がアウトになった場合も、守備位置の数字で状況を表します。たとえば、盗塁を試みてアウトになった場合は、盗塁死を示す記号（Cs）を使い、送球の経路を守備位置番号で示します。フォースアウトとダブルプレイにも、それぞれ専用の囲み記号があります。

選手交代は次のように記録します。

- **代打**: 守備位置欄に代打記号「H」を書き、その右横に選手名を記入します。次の回から守備に就いたときは、「H」の横に守備位置番号を記します。
- **代走**: 守備位置欄に代走記号「R」を書き、その右横に選手名を記入します。
- **守備交代**: 守備位置欄にポジションを書き、その右横に選手名を記入します。イニングの途中で交代があったときは、交代したタイミングで線を引いて示します。

大学野球でも、投手の継投や代打・代走が頻繁にあるため、交代の記録は忘れやすい部分です。交代があった瞬間にメモをとる習慣をつけておくと、後から整理するときに困りません。

## 慣れるための練習法：観戦しながら1試合つけてみる

記号を一覧で覚えるだけでは、実戦のスピードにはついていけません。最初のうちは、次の手順で練習するのが現実的です。

1. 守備位置番号（1〜9）を完全に覚える
2. アウトの記号（SO、F、FF、L、ゴロの数字表記）だけで、3〜4イニング分を書いてみる
3. 慣れてきたら、四死球・安打・失策・盗塁の記号を足していく
4. 試合後に、公式の記録（スコアボードや連盟の公表した結果）と見比べて、合っているかを確認する

練習の素材として、当サイトの一次データページも活用できます。たとえば、これから観戦する試合を決めるときは、[東京六大学野球 秋季の日程](https://baseballmania.jp/rikudai-2026-aki/schedule/)や、[東都大学野球1部の順位表](https://baseballmania.jp/tohto1-2026-aki/standings/)で対戦カードの状況を確認できます。リーグ戦のスコアを実際につけたあと、[東京六大学野球 秋季の順位表](https://baseballmania.jp/rikudai-2026-aki/standings/)や[投手成績ランキング](https://baseballmania.jp/rikudai-2026-aki/players/)の数字と見比べると、自分の記録がどの指標につながっているかを実感しやすくなります。

神宮球場で観戦する場合は、[神宮球場の観戦ガイド](https://baseballmania.jp/articles/jingu-kyujo-daigaku-yakyu-kansen-guide/)も参考になります。実況や解説で出てくる戦術用語の意味は、[戦術用語の一覧記事](https://baseballmania.jp/articles/daigaku-yakyu-senjutsu-yogo-guide/)にまとめています。

## 現場の声：記録を分析に使うチームの例

記録は、つけて終わりではなく、チームの課題を見つけるための材料にもなります。ツナカレメディアの取材では、ある国立大学の硬式野球部の学生が、過去6年分のデータを分析して長打不足や攻撃パターンの課題を可視化した取り組みについて話しています（[取材記事](https://media.tunakare.jp/university-students/8617818848/)、取材日2026年8月13日）。スコアブックの記録が積み上がるほど、こうした分析の元データとしての価値も高まります。

スコアラーやデータ分析担当の経験をその後のキャリアにどう活かすかについては、[スコアラー・データ分析経験の転職ガイド](https://baseballmania.jp/articles/daigaku-yakyubu-scorer-analyst-career-guide/)で整理しています。

## まとめ

スコアブックの書き方は、守備位置番号を覚えたうえで、アウト→出塁→走者・交代の順に記号を増やしていくのが基本です。早稲田式と慶応式には補助線や塁の位置の違いがあるため、まずはチームで使う様式を確認してください。ヒットか失策かといった判断に迷ったときは、公認野球規則9.00と、チームの記録担当者の基準を確認する習慣をつけることで、記録のぶれを減らしやすくなります。観戦しながら少しずつ書き慣れ、公式の結果と見比べることで、実戦でも使える記録の力が身についていきます。
