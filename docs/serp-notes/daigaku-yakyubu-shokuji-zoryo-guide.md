# SERP分析メモ: 野球部 食事メニュー 増量（P8）

作成日: 2026-10-20 / slug: `daigaku-yakyubu-shokuji-zoryo-guide`

1. 上位の顔ぶれ: 柔道・アスリート系の増量解説サイト、大学紀要（スポーツ栄養）、高校の食育資料、スポーツ栄養の企業メディア、個人ブログ。野球部の大学生に絞った記事は薄く、高校生・ジュニア向けの「補食を3〜4回」型が中心。
2. 共通点（検索意図の正解）: 筋肉で増やす（脂肪だけ増やさない）／たんぱく質の目安（体重1kgあたり約1.6〜2g）／3食に補食を足して回数で稼ぐ／朝食を抜かない。
3. 欠けている要素（差別化点）: 大学野球部の生活事情（寮・自炊・一人暮らし、授業と練習の時間割、春秋2シーズン制での増量時期の置き方）／ケガ・体調との兼ね合い／データ（リーグ戦日程・成績ページ）と結びつけた時期設計。→ 本文で大学のシーズン構造に沿った増量計画と、シーズン中の体重維持の考え方を扱い、自サイトの日程・順位ページへ内部リンクする。

## 一次情報（確認済み）
- 立命館大学・海老久美子教授（公認スポーツ栄養士）: 日本のジュニアアスリートはたんぱく質体重1kgあたり2gが目安、60kgで1日120g。補食でたんぱく質を補うのは有効 https://www.meiji.co.jp/milk-protein/research-result/tokachi/article-2.html
- ACSM/AND/DC 2016共同声明: アスリートの総たんぱく質は1.2〜2.0g/kg/日 https://www.sportgeneeskunde.com/files/bestanden/VSG/VSG6673.pdf
- 厚生労働省「日本人の食事摂取基準（2025年版）」策定検討会報告書 https://www.mhlw.go.jp/stf/newpage_44138.html
