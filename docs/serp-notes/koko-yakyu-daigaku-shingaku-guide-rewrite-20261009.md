## 2. 上位にあって自記事にない要素

- 入試制度上の位置づけ（スポーツ推薦は多くの大学で「総合型選抜」または「学校推薦型選抜」の枠として実施。早稲田大学スポーツ科学部は「総合型選抜Ⅲ群（スポーツ自己推薦入学試験）」）
- セレクションが**入学前**（高3夏など）に実施され、参加が推薦型入試の出願につながる例（東京工芸大 2027年度入学予定者向け公開セレクション。※同大は神奈川大学野球連盟所属で六大学・東都ではない）
- 進路内定の時期感（高3の6〜7月）→報道・コラムレベルのため一次情報でなく、本文採用は不可

## 3. 自記事の事実面の問題（一次情報で確認）

- 本文L16「学校推薦型選抜（旧AO・推薦入試の運動選手枠）」は誤り。文部科学省の入学者選抜実施要項見直し（2021年度入試〜）で、AO入試→総合型選抜、推薦入試→学校推薦型選抜、一般入試→一般選抜に名称変更。スポーツ推薦は大学により総合型選抜側で実施される例が多い。
- 本文L20 セレクションの定義「一般入試や他の入試方式で合格した学生を対象に」は、自サイトの姉妹記事（daigaku-yakyubu-selection-nyubu-guide / daigaku-yakyu-supotsu-suisen-guide）の定義「本人が直接コンタクトし練習参加・実技で入部可否を判断。推薦出願と組み合わされる例もある」と矛盾。東京工芸大の例も入学前実施。
