## 1. インサイト（想定読者の検索場面）

1. 大学野球を見始めたファン・保護者が「そもそも強い大学はどこなのか」を知りたい。
   プロ野球ほど順位が可視化されていないため、入口として「強豪」で検索する。
2. 高校球児・保護者が進学先候補を絞るために「強豪」で検索するが、出てくるのは
   数年前の伝統・OB紹介ばかりで「今シーズンどこが勝っているか」がわからない。
3. 東都の大学に興味を持った人が「◯◯大は強いのか」を調べたいが、東都は1部〜4部の
   階層制のため「所属部」を知らないと強さの評価がずれる。
4. 六大学・東都の試合を見に行きたい人が、どのカードが優勝争いに直結するかを知りたい。
5. 部員・OBが「自分の大学の今の立ち位置」を客観データで説明したい。

## 3. 共通点（検索意図の正解）

- 読者が求めているのは「**どの大学が強いのか**」への具体的な回答。大学名を早く挙げてほしい。
- 通算優勝回数・プロ輩出などの「伝統としての強さ」に触れることは期待されている。
- 六大学と東都という2大リーグの存在は、ほぼどの記事も前提として説明している。

## 4. 上位陣に欠けている要素（差別化点）

1. **鮮度**: 1ページ目の主要3本が2017年・2019年・更新日不明。**2026年シーズンの順位・勝敗が
   1件も載っていない**。「強豪」は年で入れ替わるのに、SERPは数年前の固定イメージのまま。
2. **勝ち点制の理解**: 大学野球は勝率でなく勝ち点で順位が決まるため、**勝率が高い大学が
   下位になる逆転が実際に起きている**（2026春・東都1部：立正大 .400＝5位／中央大 .385＝4位）。
   この「順位表の読み方」を説明した記事がSERPに存在しない。
3. **入替戦という現実**: 東都では**下部リーグで全勝優勝しても昇格できない**ことがある
   （2026春季3部：国士舘大10戦全勝→入替戦で帝京平成大に敗れ3部残留）。
   「強豪＝1部」という単純な図式が崩れる事実を、どの上位記事も扱っていない。
4. **全国での位置づけ**: 2026年の全日本大学野球選手権は関西大が優勝し、六大学・東都の
   代表は優勝していない。「六大学・東都＝最強」という前提を一次データで相対化できる。
