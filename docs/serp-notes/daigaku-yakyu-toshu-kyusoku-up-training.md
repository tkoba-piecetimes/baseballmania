# SERP分析メモ: 大学野球 投手 球速アップ トレーニング

作成日: 2026-09-23
対象KW: 大学野球 投手 球速アップ トレーニング（`docs/keyword-inventory.md` P1）

## 検索結果の顔ぶれ（WebSearch確認）

- ファーストピッチ（野球育成メディア）、フィールドフォース（用品メーカーEC）、baseball-one.com（トレーニング専門ブログ）、cyber-baseball.jp（高校野球向けコーチ塩多雅矢氏の指導記事）、アスリートワークス（中学生向けトレーニングジム）、Yahoo!知恵袋（Q&A）などが上位。
- 大学公式・連盟公式・医療機関・学会論文はほぼ登場しない（この点は既存記事P6「野球肩野球肘予防」とは競争環境が異なる）。

## 上位記事の共通点（検索意図の正解）

1. 球速アップの核は「下半身で作った力を体幹・肩・腕・指先へ連動させること」という運動連鎖の考え方。
2. 具体的なトレーニング種目（肩甲骨の瞬発トレーニング、スクワットジャンプ、片足ジャンプ、体幹トレーニング、重いボールを使った指先トレーニング等）を紹介する記事が多い。
3. 対象年代を明記しない記事が大半で、明記があっても「高校野球〜」程度。中学・高校生年代を主な読者に想定した内容が中心。

## 上位陣に欠けている要素（差別化点）

1. **大学野球特有の文脈が皆無**: 春季・秋季の2シーズン制、勝ち点制による連戦、授業・学業との両立で練習時間が限られる、といった大学野球部員特有の制約を踏まえたトレーニング計画の記事は見当たらない。
2. **一次データとの接続がない**: 上位記事はいずれも個人ブログ・メーカーサイト完結で、実際のリーグの投手成績（投球回・奪三振・防御率）や日程・オフシーズンの時期と結びつけて「いつ・どう取り組むか」を示す記事がない。自サイトの `players`（投手成績ランキング）・`standings`・`schedule` ページと接続すれば独自性を出せる。
3. **怪我予防との両立に触れていない**: 球速アップ系の記事は负荷管理・怪我予防の視点が薄い。既存記事「野球肩・野球肘の予防」との相互リンクで、球速アップと怪我予防を両立させる視点を補える。

## 差別化施策（本文に反映）

- オフシーズン（大学野球の春季・秋季の間の期間）に絞ったトレーニング計画という切り口にする。
- 東京六大学野球連盟の投手成績ランキング（`/rikudai-2026-aki/players/`）・東都大学野球連盟1部の順位表（`/tohto1-2026-aki/standings/`）への内部リンクを設置し、一次データとの接続を作る。
- 既存記事「野球肩・野球肘の予防」への内部リンクで、球速アップと怪我予防を切り離さない構成にする。
- 具体的な数値目標や実績の捏造はせず、専門家・スポーツ医学系の一次情報（該当する場合）を出典として使う。
