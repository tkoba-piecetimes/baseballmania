- 保護者が「トレーナーを仕事にするには何の資格か」「どの学部・学校を選ぶか」を知りたい
- 現役の学生マネージャー・部員が「学生トレーナーとして学ぶ道筋」を知りたい

## ② SERP（WebSearch「大学野球 学生トレーナー 資格 役割 なるには」2026-11-17）
- 検索結果は大学の学術リポジトリ論文（学生コーチ研究、体育大学の学生トレーナー報告）、JSPO関連PDF、大学のAT養成案内、早稲田ウィークリーなど。野球部の学生トレーナーに絞った「資格の要否」を整理した記事は上位に見当たらなかった
- 共通点: 資格の説明はJSPO-AT・国家資格の一般論中心で、野球部入部との関係（要否）が書かれていない
- 欠けている要素:
  1. 学生トレーナーの入部条件に資格が含まれるかを、大学公式の入部案内で確認した記述
  2. JSPO-ATの受講条件（満20歳以上・団体推薦）と大学入学直後の学生とのズレの整理
  3. 免除適応コースと国家資格の養成施設ルートの違い（学部選びとの関係）
